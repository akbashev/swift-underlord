# ``SHA256``

SHA-256 and HMAC-SHA256 that allocate nothing, on the x86 SHA extensions where the CPU has them.

## Overview

Hashing works on `Span`s and fixed-size `InlineArray`s. On x86-64 the compression function runs on SHA-NI when CPUID
says the instructions are there and they hash test messages of every padding case as the portable Swift does; the
choice is made once, at start-up (``SHA256/usesExtensions``).

``HMACSHA256`` hashes the key's inner and outer pads once, so each tag costs the message's blocks plus one: the shape
a server verifying a token per request wants.

```swift
let digest = SHA256.hash(Array("abc".utf8).span)

let mac = HMACSHA256(key: secret.span)
let tag = mac.authenticate(message.span)
```
